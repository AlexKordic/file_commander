# AR03 — Share explicit traversal policies

Status: Implemented.

## Planned solution

Extract iterative traversal with link policy, cycle identities, cancellation, errors and budgets; use it for search and operation enumeration while preserving per-operation semantics.

## Applied solution

Added a headless iterative DFS traversal service with explicit link policy, canonical directory identities, pre/postorder callbacks, cancellation, errors, entry and depth limits. Find, copy planning, delete discovery and staged tree moves use it. Find does not follow links; copy preserves its relative-link/resolve/follow policies and maps repeated directories to links; delete acts on entries in postorder. Removed the old recursive discovery helpers.

## Validation

Full native regression suite passed after correcting root output mapping in staged moves. AR03 covers Find self links, copy follow/preserve/dangling policies, 120-level trees, budgets, cancellation and delete postorder. All 14 Lua scripts passed, including the existing copy cycle/link matrix. Logs: `build/architecture-validation/AR03-*.log`.

## Differences from the plan

Traversal uses depth-first iterators rather than a breadth-first frontier, limiting live iterators to depth. Defaults are 1,000,000 entries / 1,024 levels; Find uses 100,000 entries and visibly reports truncation. Operation discovery records a budget error instead of silently continuing. Canonical identities also suppress aliases to directories already traversed.
