# AR07 — Persist logical archive locations

Status: Implemented.

## Planned solution

Represent local/archive/nested locations independently of extraction roots; restore views and bookmarks from logical identity and hold cache ownership through leases.

## Applied solution

Added a typed `Location` for local directories and nested archive chains with validated relative internal paths, durable encoding and readable captions. Settings and bookmarks retain logical identity and resolve extraction asynchronously when reopened. Archive roots now use shared leases held by panels, tabs, discovery and copy jobs; destroying the service cannot invalidate a surviving lease. Normalized the cache base to avoid macOS temporary-directory aliases breaking nested identity.

## Validation

AR07 creates real nested 7z fixtures, saves a subdirectory/bookmark, removes both cache roots, restores and reopens the bookmark, checks missing archive and parent-path rejection, and verifies lease survival/cleanup across service destruction. R16 cache regression and all 14 Lua scripts passed. Logs: `build/architecture-validation/AR07-*.log`.

## Differences from the plan

Location values use a versioned-by-prefix escaped string inside the existing version-1 settings fields, preserving compatibility with local-path settings and the public bookmark UI adapter. Cache eviction limits are applied in AR05; this commit establishes lease ownership first.
